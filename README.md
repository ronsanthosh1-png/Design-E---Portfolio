# MYP Design Portfolio

A free, static student portfolio website for showcasing MYP Design work.

## How to use
1. Open `index.html` in a browser.
2. Replace "Student Name", "Project title goes here", school/year and the placeholder text with the student's information.
3. Replace each "Add student work here" section with images, links, PDFs, videos or written evidence.
4. Keep the site folder together so the CSS works.

## Free publishing
This site uses only HTML and CSS plus one optional Google Fonts import. It can be published for free using GitHub Pages, Netlify, or Cloudflare Pages. No paid hosting or database is required.

## Important
The task-specific clarification text is a student-friendly template. Teachers should adapt wording to the exact MYP Design subject guide, school task and year-level requirements.
